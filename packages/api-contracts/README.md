# Generated API contract

`openapi.yaml` is generated from Django serializers/views by drf-spectacular.
`schema.d.ts` is generated from that schema by openapi-typescript. Do not hand-edit either.
Run `make contracts` after contract changes, then `git diff --exit-code -- packages/api-contracts` in CI to detect drift.
Only liveness/readiness are documented in Sprint 01; schema delivery is excluded from itself.
